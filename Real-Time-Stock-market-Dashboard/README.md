\# 📈 Real-Time Stock Market Dashboard



An interactive stock market dashboard built with Python, Streamlit, Pandas, Plotly, and REST API.



The application allows users to select stocks and visualize intraday market data through interactive charts and financial indicators.



\## 🚀 Features



\- 📊 Multiple stock selection

\- ⏱️ Multiple intraday intervals

\- 💰 Current stock price

\- 📈 Price change

\- 📊 Percentage change

\- 🔼 Latest high

\- 🔽 Latest low

\- 💹 Open, High and Low indicators

\- 🕯️ Interactive candlestick chart

\- 📈 Interactive price chart

\- 📊 Trading volume chart

\- 📋 Stock data table

\- 📥 Download data as CSV

\- 🔄 Manual refresh

\- ⚡ Auto-refresh option

\- 🔐 User-provided API key



\## 🛠️ Technologies



\- Python

\- Streamlit

\- Pandas

\- Plotly

\- Requests

\- REST API
