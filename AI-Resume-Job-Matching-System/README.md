# 🤖 AI-Based Resume–Job Matching System

An AI-powered resume screening system that analyzes resumes against job descriptions and ranks candidates based on their relevance.

## 🚀 Features

- Resume upload
- Job description input
- TF-IDF-based text similarity
- Skill-based matching
- Candidate ranking
- Matched skills identification
- Missing skills identification
- Final match score
- Flask web interface

## 🛠️ Technologies Used

- Python
- Flask
- Scikit-learn
- NLP
- TF-IDF
- Cosine Similarity
- HTML
- CSS
- JavaScript
- Git & GitHub

## 📊 Matching Process

1. Upload a resume
2. Enter a job description
3. Extract resume text
4. Apply TF-IDF vectorization
5. Calculate similarity
6. Compare required skills
7. Generate final score
8. Rank candidates
