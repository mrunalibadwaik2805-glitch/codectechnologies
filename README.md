# 📂 Projects

## 1. AI Resume–Job Matching System

An AI-powered web application that compares a candidate's resume with a job description and calculates a matching score based on relevant text, skills, and keywords.

### Technologies

* Python
* Flask
* Scikit-learn
* spaCy
* PostgreSQL
* HTML
* CSS
* TF-IDF
* Cosine Similarity

### Key Features

* Resume upload
* Resume text extraction
* Job description input
* Resume and job description comparison
* Matching score calculation
* Skill and keyword matching
* Web-based interface
* Database integration

📁 **Project Folder:** `AI-Resume-Job-Matching-System`
